# sixbot Calendar

Events posted in Discord with `!event`, collected by sixbot.

**Live page:** https://sixbythree.github.io/sixbot-calendar/
**Add to your calendar:** https://sixbythree.github.io/sixbot-calendar/calendar.ics

The bot writes `index.html` and `calendar.ics` here automatically. Don't edit them by hand; they get replaced on the next update.
The bot's code lives in [a2zF26](https://github.com/sixbythree/a2zF26/tree/main/05-bots/discord-bot-in-class).
